🚀 Ollama & Cline 설치 완벽 가이드

이 문서는 실제 설치 과정을 바탕으로 작성된 학습용 가이드입니다.

STEP 1. Ollama 설치 및 서버 실행

단계 1
  • 엔진 다운로드: Ollama 공식 홈페이지에서 Windows용 설치 파일을 받습니다.
  • 프로그램 설치: 다운로드된 파일을 실행하고 Install 버튼을 누릅니다.
  • 상태 확인: 윈도우 우측 하단 작업 표시줄에 라마 아이콘이 떠 있어야 합니다. 이 아이콘이 없으면 AI가 작동하지 않습니다.

STEP 2. 터미널(Git Bash)을 이용한 모델 구축

단계 2
  • Git Bash 실행: 명령어를 입력하기 위해 터미널을 엽니다.
  • 모델 설치 명령어 입력:
    ollama run qwen2.5-coder:7b
  • ⚠️ 주의했던 에러: 웹에서 명령어를 복사해 붙여넣으면 보이지 않는 공백문자가 섞여 command not found가 발생할 수 있습니다. 반드시 직접 타이핑하는 습관을 들입시다.
  • 완료 확인: 다운로드가 100% 완료되고 >>>가 뜨면 성공입니다. /exit로 빠져나옵니다.

STEP 3. VS Code 확장 프로그램(Cline) 세팅

단계 3
  • Extension 설치: VS Code 왼쪽 블록 아이콘에서 Cline을 검색하여 설치합니다. (유사품 주의: 200만 명 이상이 쓰는 정식 버전을 선택!)
  • 아이콘 고정: 아이콘이 안 보인다면 왼쪽 메뉴 바 빈 곳에서 마우스 오른쪽 클릭 후 Cline을 체크하여 활성화합니다.
  • 초기 화면 진입: Bring my own API key를 선택하고 Continue를 눌러 설정 창으로 이동합니다.

STEP 4. Cline과 Ollama 연동 설정

단계 4

Cline 화면 우측 상단의 톱니바퀴(⚙️)를 눌러 아래와 같이 설정합니다.

  • API Provider: Ollama 선택
  • Model: qwen2.5-coder:7b (목록에서 선택하거나 직접 입력)
  • 💡 참고: "Does not support Mcp" 같은 붉은 글씨는 로컬 AI의 제약사항일 뿐, 사용에 전혀 문제가 없는 정상 상태입니다.
  • 저장: 맨 아래 Done 또는 Continue를 눌러 채팅창으로 나갑니다.

STEP 5. 실제 활용 및 유지보수

단계 5
  • 프로젝트 분석: 채팅창에 @codebase를 입력하고 질문하면 내 폴더 전체를 읽습니다.
  • 버전 업데이트: Ollama 모델은 자동으로 업데이트되지 않으므로, 가끔 터미널에서 ollama pull qwen2.5-coder:7b를 입력해 최신화합니다.
  • 창 닫기: VS Code를 닫아도 Ollama(라마 아이콘)가 켜져 있다면 다음 실행 시 바로 사용할 수 있습니다.

이제 AI와 함께 스마트한 코딩을 시작해보세요! 🎉
